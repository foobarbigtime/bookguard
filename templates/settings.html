Settings

Changes are stored in {{ config_dir }}/bookguard.db and override environment defaults.

Bindery connection

BookGuard reads Bindery's database directly and uses the HTTP API only for optional actions.

Library paths

Container paths map Bindery's stored paths to the media mounted into BookGuard.

Docker bind mounts themselves are deployment settings. Changing a container path here does not create a new Docker mount; the path must already be available inside the container.

Scanning

Control what BookGuard scans and how aggressively it samples files.

Ebook inspection supports EPUB, PDF, MOBI, AZW/AZW3, CBZ ComicInfo.xml, RTF metadata, and explicit Title:/Author: headers in TXT. Unknown/unsupported formats remain REVIEW → UNSUPPORTED rather than being treated as bad.

Matching

These settings affect future classifications. Existing scan results are not rewritten.

Author matching Useful for tags like “King” instead of “Stephen King”, but less strict.
Strong semantic mismatch Requires stable embedded title + author evidence that supports neither the expected book nor any configured author alias. Generic “Chapter 1” / “Track 01” labels are ignored.
Music detection When disabled, unmatched music-like audio falls back to REVIEW.

Dashboard

Tune live updates and how many results BookGuard renders.

Safety and actions

BookGuard defaults to read-only auditing. Enable actions only after you trust its classifications.
